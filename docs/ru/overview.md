# Agent Interface Kit

Agent Interface Kit (AIK) — проект компилятора дизайна в UI. Он преобразует сохранённый дизайн и явные правила проекта в воспроизводимые исходники для веба, мобильных интерфейсов и UI-китов. Адаптеры источников и плагины вывода используют общий контракт компиляции.

Первый запланированный релиз преобразует выделение Figma в семантический HTML и CSS офлайн. В репозитории есть каркас разработки, черновые контракты и проектная документация.

## Разработка

Используйте версию Node.js из `.nvmrc` и версию npm из `package.json`.

```bash
nvm use
npm ci
npm run hooks:install
npm run check
```

Проверка запускает TypeScript, линтер с типами, проверки архитектуры и безопасности и тесты. Пакеты исходников добавляйте в `packages/`, интеграции с хостами — в `integrations/`.
