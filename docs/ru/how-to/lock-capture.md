# Зафиксируйте захват

Создайте отдельную приватную папку подготовки на томе каталога захвата. Укажите режим 0700 и владельца с UID выполняющего команду пользователя. Расширенный ACL должен отсутствовать. Сохраняйте контроль над правами и временными именами до окончания публикации. Том должен учитывать владельцев и поддерживать эксклюзивное переименование.

Передайте абсолютный путь к папке через аргумент команды.

```sh
aik lock --input ./capture --overlay ./capture/overlay.json --out ./capture/build.lock.json --staging-root "$(pwd -P)/staging"
```

При `OUTPUT_BUSY` повторите команду после завершения активной публикации. Для точного повтора используйте те же имя и входные данные. При коде выхода 1 основная ошибка указана первой. Если очистка завершилась ошибкой после публикации, точный повтор проверит опубликованный lock-файл.

[Английский оригинал](../../how-to/lock-capture.md)

Каталог захвата MUST содержать не более 4 096 прямых записей, включая существующий lock-файл. Для нового файла требуется одно свободное место.
