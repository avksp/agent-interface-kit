# Публикация плагина AIK в Figma Community

[English version](../../how-to/publish-figma-plugin.md)

Пилотный экспортёр AIK — закрытый инструмент захвата для Figma Desktop. Он привязывает попытку к документу по `figma.fileKey` и использует `enablePrivatePluginApi`. Figma предоставляет этот API только закрытым плагинам. Для публичного экспортёра AIK нужны отдельная сборка и ID публичного плагина.

[Figma Plugin API](https://developers.figma.com/docs/plugins/api/figma/)

## Подготовка публичной сборки

1. Читайте явно выбранные фреймы Figma Design через публичный Plugin API. Публичная сборка MUST обходиться без приватных API и фиксированного ключа файла. Пользователь выбирает фреймы для экспорта.
2. Экспортируйте сохранённый захват и нужные ассеты. Проверьте его по контракту снимка AIK и выполните `aik lock`, `aik compile` и `aik verify` на характерном примере. Проверьте пустое выделение, поддерживаемый фрейм и обязательную неподдерживаемую функцию.
3. Создайте или импортируйте плагин разработки в Figma Desktop. Используйте постоянный ID, выданный Figma. Манифест MUST указывать точки входа, тип редактора Design и сетевой доступ. Офлайн-экспортёр использует `networkAccess.allowedDomains: ["none"]`. Проверьте, что интерфейс сохраняет ожидаемый файл.

[Справочник манифеста Figma](https://developers.figma.com/docs/plugins/manifest/)

## Отправка плагина

1. Откройте Design-файл в Figma Desktop для macOS или Windows. В **Plugins → Manage plugins** выберите **Publish** рядом с плагином разработки. Аккаунт Starter позволяет отправлять классические плагины из Desktop.
2. Выберите **Community**, если Figma предлагает выбрать место публикации. Укажите название, слоган, описание, категорию и контакт поддержки. Подготовьте иконку 128×128 и обложку 1920×1080. Для публичных изображений или примера используйте синтетический дизайн.
3. Проверьте указанный сетевой доступ и заполните относящиеся к плагину сведения о безопасности. Выберите **Publish**, чтобы отправить первую сборку на проверку Figma.
4. Дождитесь статуса **Published**. Откройте карточку Community и запустите установленную копию в отдельном тестовом файле. Проверьте экспорт и импорт в CLI на этой копии. Для обновления используйте **Publish new version** с тем же ID плагина.
