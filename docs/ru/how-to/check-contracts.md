# Проверка контракта JSON

[English version](../../how-to/check-contracts.md)

1. Откройте корень репозитория. Используйте версию Node.js из `.nvmrc`.
2. Установите закреплённые зависимости командой `npm ci`.
3. Измените схему и её пример в `schemas/`. Значения полей приведены в [справочнике контрактов](../reference/contracts.md).
4. Если меняется структурное правило, обновите или добавьте тест в [contracts.test.mjs](../../../tests/contracts.test.mjs). Включите допустимое и недопустимое значения для этого правила.
5. Запустите `npm run check:contracts`. Примеры должны пройти, недопустимые записи — получить отказ.
6. Запустите `npm run check`, чтобы проверить типы, линтер, защитные правила, контракты и ссылки документации.

Если схема отклоняет ранее поддерживаемый вход, определите, как сохранить совместимость. При необходимом несовместимом изменении используйте новую версию схемы и опишите переход.
