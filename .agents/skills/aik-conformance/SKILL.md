# AIK conformance checks

Test the promised behavior through its public entry point. Use fixed versions and references that are independent of the compiler output. [Verification](../../../docs/verification.md)

- Run the same lock in two empty directories. Compare every relative path, SHA-256 digest, and stable diagnostic field. For a harness claim, send the same request through each declared interface. Test a retry and a changed output directory.
- Check the rendered geometry, semantic roles, and expected actions. Record the platform, renderer, viewport or device, fonts, and tolerance. Use a real export, build, or run to verify editor and SDK routes.
- For an invalid case, check the code, `sourceRef`, and absence of partial output. Run the previous supported corpus after a target change.
- For size and speed, record the method, raw values, and conditions. Mark unavailable values as unknown. When using ALK, store evidence at the path in the active plan. [Contract reference](../../../docs/reference/contracts.md)
